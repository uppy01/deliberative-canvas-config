# deliberative-canvas-config

This repository is for configuration files that serve to populate/hydrate the [Deliberative Canvas App](https://github.com/uppy01/deliberative-canvas-app) such that updates can be made without having to re-build/release the app and/or host a database.

It may also hold data/templates/outputs from deliberative tools that the app interoperates with - see [dt-output-examples](/dt-output-examples/)

If you are looking for the Kumu template to fork, [try here](https://kumu.io/mark-u/deliberative-canvas-template)

Deliberative Canvas documentation can be found [here](https://deliberative-canvas.gitbook.io/deliberative-canvas-docs)

Deliberative Canvas server repo can be found [here](https://github.com/uppy01/deliberative-canvas-server)
